# Stagelight

Worship presentation software for Windows that you run from your phone.

This repository holds the installers and automatic updates. To install, download **`Stagelight-Setup-<version>.exe`** from the [latest release](https://github.com/Lord-Raven1/Stagelight-Release/releases/latest) and run it. Installed copies keep themselves up to date.

Windows may say it "protected your PC" because the installer isn't signed: choose **More info → Run anyway**.
